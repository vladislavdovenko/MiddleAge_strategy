# Middle Age Strategy

Інтерактивний полігон феодальної кампанії для Windows x64, Godot 4.7.2. Розпакуйте ZIP і відкрийте MiddleAge.exe.

## Керування

«Феодал» обирає персонажа. Клацніть місце призначення на карті. «Наказ обозу» перемикає той самий клік на розпорядження для обозу. Поруч він отримує наказ особисто. На відстані потрібен посильний біля феодала й остання відома позиція обозу. Посильний іде до цього місця, шукає адресата в межах власного огляду, а після зустрічі повертається. Якщо обоз зник з відомого місця, доставка може затриматись.

ПКМ із перетягуванням, WASD або стрілки пересувають камеру. Колесо змінює масштаб. Пауза й режими ×1, ×10, ×60, ×600 керують часом кампанії. Південну переправу за сценарієм зачиняють о 07:00 та відчиняють о 18:00 за умови, що на ній немає групи. Кнопка стану переправ показує окремо побачені та застарілі відомості.

## Редактор і збереження

У редакторі симуляцію призупинено. Виберіть об’єкт на карті або у списку, перетягніть, змініть розмір, шар 1–10 чи віддзеркалення. У каталозі «Розмістити» додає екземпляр. Для ділянки місцевості виберіть тип і клацніть два протилежні кути. На спільному шарі порядок залежить від точки опори. «Зберегти карту» записує декорації та прохідність у user://valley-objects-v1.json. «Зберегти партію» записує групи, годинник, наказ, переправи та останні спостереження у user://campaign-v1.save. Для відтворення маршруту після завантаження використовуйте ту саму редакцію карти.

## Дані та перевірки

data/valley.json містить регіони, геометрію водойм і доріг, переправи, декорації та поверхні. data/campaign.json задає акторів, місця відкриття, події, профіль висот, перешкоди огляду, кольори та дальність огляду чотирьох фаз доби. Світ використовує безперервні координати. У sim/sight.gd висота є сумою гладких пагорбів. На відкритому місці огляд зростає з висотою, ліс обмежує дальність. Промінь до цілі перевіряє проміжний рельєф і перешкоди від об’єктів. Фільтр доби охоплює світовий шар із ландшафтом і спрайтами.

Після імпорту ресурсів запустіть Godot із --headless --script res://tests/run.gd, потім так само tests/map_checks.gd і tests/navigation_load.gd. На Windows tools/build.ps1 виконує перевірки та експорт. GitHub Actions додатково порівнює відрендеровані кадри й запускає експортований EXE.
