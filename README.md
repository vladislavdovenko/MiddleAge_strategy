# Middle Age Strategy · інтерактивна карта

Windows x86-64 · Godot 4.7.2 stable. Розпакуйте архів та відкрийте MiddleAge.exe. Віз починає демонстраційний рейс від Вільшан до Млинова. Клацніть на будь-яку доступну ділянку поля чи дороги, щоб змінити його маршрут. Кнопка «Проїхати через міст» задає пункт призначення на протилежному березі.

Колесо миші й кнопка «Масштаб» перемикають огляд і близький план. У близькому плані тягніть карту правою кнопкою. Кнопка мосту змінює доступ до переправи. Якщо віз уже на мосту, спершу дайте йому виїхати. Пауза й швидкості ×1, ×10, ×60, ×600 керують єдиним годинником. Партія починається о 06:00.

## Полігон та перевірки

Фізична геометрія берега, межі мосту, дорога, початкова позиція та художні розміщення задаються в data/valley.json. Регіони підключаються окремими файлами. Позиція воза в метрах належить моделі світу, обидва відображення використовують ту саму позицію. Пошук займається малим графом опорних точок із тимчасовими вузлами для старту й цілі. Він перевіряє прохідність сегментів та мінімізує час серед маршрутів графа. Таблиця швидкостей і множники поверхонь задають тривалість переходу.

Спрайти підготовлено з наданих автором проєкту ілюстрацій. Рівні дерева та воза визначають їх перекриття, а рух колеса прив’язано до пройденої відстані. Збереження партії належить до наступного етапу.

## Відтворення з чистої копії

- З кореня проєкту запустіть `godot --headless --script res://tests/run.gd` або `sh tools/test.sh`. Код виходу 0 означає успіх. Для перевірки самого тестового запуску додайте `-- --prove-failure`: очікується код 1.
- Для Windows установіть стандартний Godot 4.7.2 і його офіційні export templates цієї ж версії. У PowerShell запустіть `./tools/build.ps1 -Godot 'C:/Godot/Godot_v4.7.2-stable_win64_console.exe'`, вказавши свій шлях. Скрипт імпортує проєкт, запускає тести й експортує в build/MiddleAge.exe. Запускайте гру з усіма файлами каталогу build.
- GitHub Actions виконує ту ж збірку на Windows, запускає експортовану програму й зберігає каталог як артефакт MiddleAge-stage2-windows-x64. Завантаження доступне зі сторінки успішного запуску workflow.

Після імпорту проєкту запустіть також `godot --headless --script res://tests/map_checks.gd` для перевірки прохідності, команд миші, масштабу, регіонів і годинника.

## Модель

Годинник вимірює цілі секунди. Для першого полігона кожна з чотирьох фаз триває шість годин, відлік починається з ранку. Симуляція не залежить від SceneTree. Графічний адаптер накопичує частки секунди, передає цілі кроки й під час паузи зупиняє просування часу. Позиція обчислюється від початку чинного маршруту. Подія прибуття має час першої цілої секунди досягнення цілі та порядковий номер наказу. Новий наказ замінює незавершений маршрут.

Швидкість типу cart у метрах за секунду задає data/unit_types.tsv. Початковий контрольний маршрут має довжину 600 м, приймальний тест розраховано на 2 м/с.

## Редактор об’єктів

Натисніть «Редактор». Для нового екземпляра виберіть рисунок у каталозі, натисніть «Розмістити» й клацніть по карті. Наявний об’єкт можна вибрати кліком по його силуету або за ID у списку «На карті», навіть коли його повністю закриває інший об’єкт. Тягніть мишею, щоб перемістити. 100% означає вихідний розмір спрайта в грі. Доступні два дзеркальні відображення, видалення та шари 1–10.

На спільному шарі предмети перекривають один одного за вертикальною координатою опори. Віз і початкові дерева мають шар 5; нижчий шар завжди позаду, вищий завжди попереду. Редактор призупиняє модельний час. Повторне натискання «Редактор» повертає до гри зі зміненою композицією. Кнопка «Зберегти карту» записує розміщення у user://valley-objects-v1.json. При наступному запуску гра відкриває цей файл. Декоративний віз у каталозі є окремим нерухомим об’єктом.
