# Middle Age Strategy

Етапи 0–1. Godot **4.7.2 stable**, стандартна збірка, GDScript, рендерер Compatibility. Відкрийте project.godot у редакторі й натисніть F6 для відкритої main.tscn або F5 для проєкту. На екрані показано шлях воза, модельний час і фазу доби. Є пауза, швидкості ×1 та ×60 і повторний старт.

## Відтворення з чистої копії

- З кореня проєкту запустіть `godot --headless --script res://tests/run.gd` або `sh tools/test.sh`. Код виходу 0 означає успіх. Для перевірки самого тестового запуску додайте `-- --prove-failure`: очікується код 1.
- Для Windows установіть стандартний Godot 4.7.2 і його офіційні export templates цієї ж версії. У PowerShell запустіть `./tools/build.ps1 -Godot 'C:/Godot/Godot_v4.7.2-stable_win64_console.exe'`, вказавши свій шлях. Скрипт імпортує проєкт, запускає тести й експортує в build/MiddleAge.exe. Запускайте гру з усіма файлами каталогу build.
- GitHub Actions виконує ту ж збірку на Windows, запускає експортовану програму й зберігає каталог як артефакт MiddleAge-windows-x64. Завантаження доступне зі сторінки успішного запуску workflow.

## Модель

Годинник вимірює цілі секунди. Для першого полігона кожна з чотирьох фаз триває шість годин, відлік починається з ранку. Симуляція не залежить від SceneTree. Графічний адаптер накопичує частки секунди, передає цілі кроки й під час паузи зупиняє просування часу. Позиція обчислюється від початку чинного маршруту. Подія прибуття має час першої цілої секунди досягнення цілі та порядковий номер наказу. Новий наказ замінює незавершений маршрут.

Швидкість типу cart у метрах за секунду задає data/unit_types.tsv. Початковий контрольний маршрут має довжину 600 м, приймальний тест розраховано на 2 м/с.
